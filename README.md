# INNER CIRCLE — Full Workflow Automation for Creative Teams

Single-screen, custom-gesture-driven 3D creative workflow showcase built with React 19, TypeScript, Three.js WebGL, GSAP 3, and Tailwind CSS.

## Features
- **3D Floating Craggy Rock Monolith Island**: Real-time Three.js WebGL sculpted floating monolith with dual-reveal shader (scroll-driven linear wipe and cursor spotlight radial reveal).
- **GSAP Split-Text & Parallax Controller**: Custom wheel/touch gesture controller lerping `scrollProgress` across the Hero Monolith, Manifesto (`01 — WHY WE EXIST`), 3D Cylindrical Workflow Drum, and Triple-Row Kinetic Marquee.
